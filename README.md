# 中国国家地理 · 特别刊物目录

统计展示中国国家地理杂志社历年出版的**省份专辑 / 特刊 / 增刊 / 附刊**的工作台。

静态单文件应用，零依赖，不联网，不登录。所有数据存在仓库里，页面只读。

**线上地址：<https://sunyh-gi.github.io/cng-catalog/>**　仓库：[Sunyh-gi/cng-catalog](https://github.com/Sunyh-gi/cng-catalog)

## 加一期刊目

一条命令，同时做三件事：归档原图、生成缩略图、写入数据。

```bash
python _add_cover.py \
  --src "C:/Users/Mickey/Downloads/202602.jpg" \
  --id 2026-02 \
  --year 2026 \
  --issue 2 \
  --type province \
  --title "2026年第2期 黑龙江专辑（下）"
```

| 参数 | 说明 |
|---|---|
| `--src` | 封面原图路径 |
| `--id` | 刊目唯一标识，同时作为封面文件名（不含扩展名） |
| `--year` | 年份 |
| `--issue` | 期号；增刊 / 特刊没有期号时省略 |
| `--type` | `province` 省份专辑 / `special` 特刊 / `supplement` 增刊 / `appendix` 附刊 |
| `--title` | 刊名，严格按命名规范书写 |

脚本会按「年份降序 + 同年期号降序」自动重排，同年内无期号的条目排在最后。

已经存在的 `--id` 会被覆盖，因此改刊名或换封面直接重跑同一条命令即可。

### 刊名命名规范

| 类别 | 格式 | 示例 |
|---|---|---|
| 省份专辑 | `XXXX年第X期 XX专辑（上/下）` | 2026年第1期 黑龙江专辑（上） |
| 10 月特刊 | `XXXX年第10期 XXX` | 2025年第10期 选美中国20周年 |
| 特刊 / 增刊 | `XXXX年特刊或增刊 XXX` | 2025年特刊 神武峡 |
| 附刊 | `XXXX年第X期 附刊 XXX` | 2024年第4期 附刊 门头沟 |

口径说明：**类型词只出现一次**，放在前缀里（例「2025年特刊」），后缀只写名称（例「神武峡」），不要写成「2025年特刊 神武峡特刊」。

### 刊目 id 建议写法

| 类别 | 写法 | 示例 |
|---|---|---|
| 常规期 | `YYYY-NN` | `2026-01` |
| 特刊 / 增刊 | `YYYY-TK-短名` | `2025-TK-shenwuxia` |
| 附刊 | `YYYY-FK-短名` | `2024-FK-mentougou` |

id 只用小写字母、数字和连字符，避免中文和空格，以免跨平台文件名出问题。

## 数据字段

`catalog.js` 里每条记录：

```js
{
  "id":    "2026-01",                        // 唯一标识，也是封面文件名
  "year":  2026,                             // 年份
  "issue": 1,                                // 期号，无期号为 null
  "type":  "province",                       // province / special / supplement / appendix
  "title": "2026年第1期 黑龙江专辑（上）"      // 刊名
}
```

`catalog.js` 顶部还有一个 `window.CNG_CATALOG_UPDATED`，由录入脚本自动写成当天日期，页脚显示的「数据更新」读的就是它。

## 拥有状态标记

点刊目卡片上**除封面以外的任何位置**，屏幕中央弹出一张全屏遮罩上的卡片（`z-index` 高于封面放大层，是页面上优先级最高的浮层），卡片里显示这一期的刊名和两个选项「已购 / 未购」。选「已购」后，该卡片刊名下方会出现一个 6×6 的绿色小圆点（比信息区左缘右移 3px），一眼看出哪些已经收进书架。选「未购」则不加任何标记。

- 点**封面**仍然是放大原图，不会弹这张卡片。
- 点遮罩空白处或按 Esc 取消；弹层打开时滚轮被吃掉，背后的列表不会跟着滚。
- 标记存在浏览器本地（`localStorage` 的 `cng-owned-v1`），是**每位访客自己的标记**，不会写回仓库。
- 想让某条刊目对所有人默认显示为已购，在 `catalog.js` 的对应条目里加 `"owned": true` 即可；访客本地的标记优先级更高。

## 封面显示规则（重要 · 不要改回 cover）

杂志封面**不是统一的 3:4**。实测三张：`2026-01` = 0.7500、`2026-02` = 0.7494、`2026-TK-yunyang` = **0.7215**。

因此卡片封面一律用 **`object-fit: contain`**：整张按原比例放进 81×108 的框，短的那边留浅灰底（`--fill` #F5F5F6），像裱在卡纸上。最瘦的那张左右各留 1.6px，肉眼几乎看不出，但**任何比例的封面都不会丢内容**。

改成 `object-fit: cover` 会立刻开始切边（实测会把云阳增刊上下各切掉约 2px，红色出血边被削掉）。冒烟测试的 F 段专门守这条。

缩略图文件由 `_add_cover.py` 用 `Image.thumbnail()` 生成，**保持原比例、不做任何裁切**，所以非 3:4 的封面产出的是 462×640 这类非标尺寸 —— 这是预期的。

## 排序

右上角的排序控件有三个方式：

| 方式 | 顺序 |
|---|---|
| **最近出版**（默认） | 年份降序 → 同年期号降序；无期号者垫在同年末尾 |
| **最早出版** | 年份升序 → 同年期号升序；无期号者垫在同年末尾 |
| **按期号** | 年份降序 → 同年期号**升序**（第 1 期 → 第 2 期 → … → 第 10 期）；无期号者垫在同年末尾，末尾内部按「附刊 → 增刊 → 特刊」 |

**点进年份页会自动切到「按期号」**，那一年就按自然阅读顺序排一遍；**点回「全部」会自动回到「最近出版」**。

按期号排序下，同一个期号撞车时（例如某一期正刊和它的附刊），正刊排在前。

## 看效果

```bash
node _shot.js                      # 真实数据整屏截图 → _shot.png
node _shot.js --mock               # 注入 38 条模拟数据 → _shot_mock.png
node _shot.js --clip=0,0,780,200   # 只截指定区域（x,y,w,h），用来放大核对几像素级对齐 → _shot_crop.png
node _shot.js --owned              # 把当前数据全部标为已购，核对绿色小圆点 → _shot_owned.png
node _shot.js --open               # 打开第一张卡片的「已购 / 未购」弹层 → _shot_open.png
node _shot.js --year=2025          # 先点进该年份页再截图 → _shot_y2025.png
node _shot.js --url=https://sunyh-gi.github.io/cng-catalog/   # 复核线上站点（不起本地服务）→ _shot_live.png
```

真实刊目还很少时，用 `--mock` 才能看出 3 列网格和筛选行的真实排布。`--clip` 只截一块区域再看，是核实几像素级对齐最省事的办法。`--url` 用来确认「推上去之后线上真的是对的」，跟本地跑的结果不是一回事。

## 发布

托管在 GitHub Pages：

- 仓库：<https://github.com/Sunyh-gi/cng-catalog>（public）
- 线上：<https://sunyh-gi.github.io/cng-catalog/>
- Pages 源：`main` 分支根目录，纯静态，不需要构建

改完代码或数据后的流程：

1. 跑 `node _smoke.js`，确认 57/57
2. 在 `CHANGELOG.md` 追加本版本改了什么，并按规则抬版本号
3. 同步改 `index.html` 里的 `APP_VERSION`（A7 检查三者必须一致）
4. 推送：

```bash
node _gh_push.js                     # 推送（新增刊目会被自动扫进清单）
node _gh_push.js --create            # 仓库不存在时先建仓（public）
node _gh_push.js --pages             # 顺带开启 GitHub Pages（main / root）
node _gh_push.js --msg "提交说明"     # 自定义提交说明
```

5. 等一两分钟 Pages 构建完，`node _shot.js --url=https://sunyh-gi.github.io/cng-catalog/` 复核线上

### 推送脚本怎么拿凭据

`_gh_push.js` 优先读环境变量 `GHPAT`，没有就读同目录的 `.gh_token`。token 用 GitHub 的 **classic PAT**（Settings → Developer settings → Personal access tokens → Tokens (classic)，勾 `repo` 权限），一行一个，文件末尾不要留多余空行。

`.gh_token` 已经加进 `.gitignore`，不会进版本库 —— 但也意味着**换机器要重新放一份**。

推送走 Contents API 而不是 git CLI，是因为本机 Git Bash 的 PATH 不完整（`dirname` 等 coreutils 缺失），git 命令行不可用；顺带也避免了 JPEG 二进制被 git 的换行符处理搞坏。每个文件写完会回读 sha 做校验，所以**正常情况下必定有逐文件的 sha 输出**；如果一行没输出却 exit 0，那是空跑，要查。

# 中国国家地理 · 特别刊物目录

统计展示中国国家地理杂志社历年出版的**省份专辑 / 特刊 / 增刊 / 附刊**。

静态单文件应用，零依赖、不联网、不登录。数据全部存在仓库里，页面只读。

**线上地址：<https://sunyh-gi.github.io/cng-catalog/>**　仓库：[Sunyh-gi/cng-catalog](https://github.com/Sunyh-gi/cng-catalog)

---

本地打开：双击 `index.html` 即可，不需要起服务。

## 加一期刊目

一条命令，同时做三件事：归档原图、生成缩略图、写入数据。

```bash
python _add_cover.py \
  --src "D:/covers/202602.jpg" \
  --id 2026-02 \
  --year 2026 \
  --issue 2 \
  --type province \
  --title "2026年第2期 黑龙江专辑（下）"
```

| 参数 | 说明 |
|---|---|
| `--src` | 封面原图路径 |
| `--id` | 刊目唯一标识，同时作为封面文件名（不含扩展名） |
| `--year` | 年份 |
| `--issue` | 期号；增刊 / 特刊没有期号时省略 |
| `--type` | `province` 省份专辑 / `special` 特刊 / `supplement` 增刊 / `appendix` 附刊 |
| `--title` | 刊名，严格按下面的命名规范书写 |

脚本会按「年份降序 + 同年期号降序」自动重排，同年内无期号的条目排在最后。已经存在的 `--id` 会被覆盖，所以改刊名或换封面直接重跑同一条命令即可。

### 刊名命名规范

| 类别 | 格式 | 示例 |
|---|---|---|
| 省份专辑 | `XXXX年第X期 XX专辑（上/下）` | 2026年第1期 黑龙江专辑（上） |
| 10 月特刊 | `XXXX年第10期 XXX` | 2025年第10期 选美中国20周年 纪念版 |
| 特刊 / 增刊 | `XXXX年特刊或增刊 XXX` | 2025年特刊 神武峡 |
| 附刊 | `XXXX年第X期 附刊 XXX` | 2024年第4期 附刊 门头沟 |

两条口径：

1. **类型词只出现一次**，放在前缀里（例「2025年特刊」），后缀只写名称（例「神武峡」），不要写成「2025年特刊 神武峡特刊」。
2. **月份一律写成「第X期」**（1 月 = 第 1 期，10 月 = 第 10 期），不要写「XXXX年X月」，这样同年各期才能按期号自然排序。

### 刊目 id 建议写法

| 类别 | 写法 | 示例 |
|---|---|---|
| 常规期 | `YYYY-NN` | `2026-01` |
| 特刊 / 增刊 | `YYYY-TK-短名` | `2025-TK-shenwuxia` |
| 附刊 | `YYYY-FK-短名` | `2024-FK-mentougou` |

id 只用小写字母、数字和连字符，避免中文和空格，以免跨平台文件名出问题。

## 数据字段

`catalog.js` 里每条记录：

```js
{
  "id":    "2026-01",                        // 唯一标识，也是封面文件名
  "year":  2026,                             // 年份
  "issue": 1,                                // 期号，无期号为 null
  "type":  "province",                       // province / special / supplement / appendix
  "title": "2026年第1期 黑龙江专辑（上）"      // 刊名
}
```

`catalog.js` 顶部还有一个 `window.CNG_CATALOG_UPDATED`，由录入脚本自动写成当天日期，页脚显示的「数据更新」读的就是它。

## 拥有状态标记

点刊目卡片上**除封面以外的任何位置**，会弹出一张居中的卡片，上面写着这一期的刊名和两个选项「已购 / 未购」。选「已购」后，该卡片刊名下方会出现一个绿色小圆点，一眼看出哪些已经收进书架；选「未购」则不加任何标记。

- 点**封面**仍然是放大原图，不会弹这张卡片。
- 点卡片外或按 Esc 取消。
- 标记存在浏览器本地（`localStorage` 的 `cng-owned-v1`），是**每位访客自己的标记**，不会写回仓库。
- 想让某条刊目对所有人默认显示为已购，在 `catalog.js` 的对应条目里加 `"owned": true` 即可；访客本地的标记优先级更高。

## 排序

右上角的排序控件有三个方式：

| 方式 | 顺序 |
|---|---|
| **最近出版**（默认） | 年份降序 → 同年期号降序；无期号者垫在同年末尾，末尾内部按「附刊 → 增刊 → 特刊」 |
| **最早出版** | 年份升序 → 同年期号升序；无期号者垫在同年末尾，末尾内部同上 |
| **按期号** | 年份降序 → 同年期号**升序**（第 1 期 → 第 2 期 → … → 第 10 期）；无期号者垫在同年末尾，末尾内部按「附刊 → 增刊 → 特刊」 |

**点进年份页会自动切到「按期号」**，那一年就按自然阅读顺序排一遍；**点回「全部」会自动回到「最近出版」**。

按期号排序下，同一个期号撞车时（例如某一期正刊和它的附刊），正刊排在前。同年多张无期号的排序，三个模式口径一致，不会因为切换视图而互换位置。

## 封面显示

杂志封面**并不统一是 3:4**（实测从 0.66 到 0.77 都有）。因此卡片封面一律用 `object-fit: contain`：整张按原比例放进框里，短的那边留浅灰底，像裱在卡纸上，**任何比例的封面都不会丢内容**。

缩略图由 `_add_cover.py` 按原比例生成、不做裁切，所以非 3:4 的封面产出的是 462×640 这类非标尺寸 —— 这是预期的。
